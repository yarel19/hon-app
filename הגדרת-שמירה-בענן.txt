הפעלת חשבון וסנכרון ב-HON

צריך לבצע את השלבים פעם אחת בלבד:

1. היכנס ל-https://supabase.com וצור חשבון חינמי.
2. צור פרויקט חדש ובחר סיסמה חזקה למסד הנתונים.
3. בתפריט הפרויקט פתח SQL Editor.
4. פתח את הקובץ supabase-setup.sql שנמצא בתיקיית HON.
5. העתק את כל תוכנו ל-SQL Editor ולחץ Run.
6. ב-Supabase פתח Project Settings ואז API.
7. העתק את Project URL.
8. העתק את Publishable key או anon public key.
9. פתח את HON ולחץ על "הפעלת שמירה בענן".
10. הדבק את שני הפרטים ושמור.
11. צור חשבון בתוך HON עם האימייל והסיסמה שלך.
12. אם נשלח אימייל אישור, אשר אותו ואז התחבר.

חשוב:
- לעולם אל תכניס לאפליקציה את service_role key.
- המפתח המתאים נקרא Publishable key או anon public.
- לאחר החיבור תראה למטה "נשמר בענן".
- אפשר להתחבר באותו חשבון מהטלפון ומהמחשב.
