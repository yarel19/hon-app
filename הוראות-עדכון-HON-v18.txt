עדכון ל-HON v18
================

1. חלץ את HON-v18-stitch-exact.zip.
2. היכנס למאגר hon-app ב-GitHub.
3. לחץ Add file ואז Upload files.
4. העלה את כל הקבצים שחולצו ואשר החלפה.
5. לחץ Commit changes.
6. המתן כדקה ופתח את האתר מחדש.
7. בטלפון סגור את האפליקציה לגמרי ופתח מחדש.

הנתונים אינם נמצאים בקובצי הקוד ולכן ההחלפה לא מוחקת אותם.
אין למחוק טבלאות ב-Supabase ואין צורך לשחזר את הגיבוי.
