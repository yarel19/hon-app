HON Stitch v23 - הוראות עדכון קצרות

1. הורד את הקובץ HON-Stitch-v23.zip וחלץ אותו.
2. היכנס למאגר GitHub שבו נמצאת האפליקציה.
3. העלה לתיקייה הראשית את כל הקבצים והתיקייה fonts שנמצאים בתוך התיקייה שחילצת.
4. כאשר GitHub שואל, אשר החלפה של הקבצים הקיימים.
5. המתן לסימון הירוק של GitHub Pages.
6. במחשב ובטלפון סגור את האפליקציה ופתח מחדש. אם עדיין מוצגת הגרסה הקודמת, רענן פעם אחת.

חשוב:
- אין צורך להריץ מחדש את supabase-setup.sql.
- הנתונים הקיימים אינם נמחקים. מבנה הנתונים נשאר בגרסה 17 וקובץ הסנכרון נשאר ללא שינוי.
- מומלץ לשמור את הגיבוי המלא שכבר הורדת עד שתוודא שהגרסה החדשה נפתחת בשני המכשירים.
