HON Stitch v47 — הוראות עדכון

1. חלץ את HON-Stitch-v47.zip.
2. היכנס למאגר hon-app ב-GitHub.
3. לחץ Add file ואז Upload files.
4. העלה את כל התוכן שחולץ, כולל:
   - notifications.js
   - תיקיית fonts
   - תיקיית supabase
   - קובצי ה-SQL וההוראות
5. לחץ Commit changes והמתן 2–3 דקות לפרסום.
6. במחשב בצע Ctrl+F5. בטלפון סגור את האפליקציה ופתח אותה מחדש.

אין צורך לייבא גיבוי מחדש. כל הנתונים הקיימים נשמרים ומשודרגים אוטומטית.

כל השינויים עובדים מיד לאחר ההעלאה, למעט התראות שפועלות כשהאפליקציה סגורה.
