HON Stitch v22 — הוראות עדכון פשוטות
=====================================

מה חשוב לדעת
-------------
העדכון משדרג את הצבעים, העומק והאנימציות בלי לשנות את מבנה האפליקציה.
כל התנועות, החשבונות, התקציבים, הארנקים, המטרות, החובות וסגירות החודש נשמרים.
מבנה הנתונים וסנכרון הענן נשארו זהים. אין להריץ שוב SQL ב-Supabase.

איך לעדכן ב-GitHub
------------------
1. שמור את קובץ הגיבוי המלא שכבר הורדת.
2. חלץ את קובץ ה-ZIP למחשב.
3. במאגר GitHub לחץ Add file ואז Upload files.
4. גרור את כל הקבצים ואת תיקיית fonts מתוך התיקייה שחולצה.
5. אשר החלפה ולחץ Commit changes.
6. המתן כשתי דקות ופתח מחדש את האתר.

אם עדיין מופיע העיצוב הישן
--------------------------
במחשב: לחץ Ctrl+F5.
בטלפון: סגור את האפליקציה לגמרי ופתח שוב.
אם עדיין ישן, פתח פעם אחת בדפדפן ורענן.

סנכרון
------
התחבר באותו אימייל במחשב ובטלפון.
אחרי שינוי, המתן כמה שניות או לחץ על סמל הסנכרון.
