HON Stitch v19 — הוראות עדכון פשוטות
=====================================

מה חשוב לדעת
-------------
העדכון מחליף את העיצוב בלבד וממשיך להשתמש בדיוק באותו מבנה נתונים ובאותו סנכרון ענן.
התנועות, החשבונות, התקציבים, הארנקים, המטרות, החובות והיסטוריית סגירת החודש אינם נמחקים.
אין צורך להריץ שוב את קובץ ה-SQL ב-Supabase.

איך לעדכן ב-GitHub
------------------
1. לפני העדכון, שמור אצלך את קובץ הגיבוי המלא שכבר הורדת.
2. חלץ את קובץ ה-ZIP למחשב.
3. היכנס למאגר GitHub שבו נמצאת האפליקציה.
4. לחץ Add file ואז Upload files.
5. גרור לחלון את כל הקבצים שחולצו מתוך ה-ZIP.
6. אשר החלפה של הקבצים הקיימים ולחץ Commit changes.
7. המתן כשתי דקות ופתח מחדש את כתובת האתר.

אם עדיין מופיע העיצוב הישן
--------------------------
במחשב: לחץ Ctrl+F5.
בטלפון: סגור את האפליקציה לגמרי ופתח שוב. אם עדיין ישן, פתח פעם אחת בדפדפן ורענן.

סנכרון
-------
היכנס באותו אימייל גם במחשב וגם בטלפון. אחרי שינוי, המתן כמה שניות או לחץ על סמל הסנכרון.
אם שני המכשירים היו פתוחים בזמן העדכון, רענן את שניהם פעם אחת.
