HON Stitch v48 — הוראות עדכון

1. חלץ את HON-Stitch-v48.zip.
2. היכנס למאגר hon-app ב-GitHub.
3. לחץ Add file ואז Upload files.
4. העלה את כל התוכן שחולץ, כולל תיקיות fonts ו-supabase.
5. לחץ Commit changes והמתן 2–3 דקות לפרסום.
6. במחשב בצע Ctrl+F5 כדי לטעון מיד את העיצוב החדש.

אין צורך לייבא גיבוי מחדש. כל הנתונים הקיימים נשמרים, והעדכון משנה רק את פריסת המסך.
