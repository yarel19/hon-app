עדכון HON Stitch v41

1. חלץ את קובץ HON-Stitch-v41.zip.
2. העלה ל-GitHub את כל הקבצים והתיקייה fonts שבתוך התיקייה שחולצה.
3. אשר החלפה של הקבצים הקיימים.
4. המתן כדקה לפרסום GitHub Pages.
5. במחשב בצע רענון חזק: Ctrl+F5.
6. בטלפון סגור את האפליקציה לחלוטין ופתח מחדש. אם צריך, רענן פעם אחת בדפדפן.

אין צורך להריץ SQL ואין צורך למחוק נתונים.
