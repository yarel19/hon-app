HON Stitch v21 — הוראות עדכון פשוטות
=====================================

מה חשוב לדעת
-------------
העדכון משפר את העיצוב והסידור בלבד.
הוא ממשיך להשתמש באותו מבנה נתונים ובאותו סנכרון ענן.
כל התנועות, החשבונות, התקציבים, הארנקים, המטרות, החובות וסגירות החודש נשמרים.
אין צורך להריץ שוב את קובץ ה-SQL ב-Supabase.

איך לעדכן ב-GitHub
------------------
1. שמור אצלך את קובץ הגיבוי המלא שכבר הורדת.
2. חלץ את קובץ ה-ZIP למחשב.
3. היכנס למאגר GitHub שבו נמצאת האפליקציה.
4. לחץ Add file ואז Upload files.
5. גרור לחלון את כל הקבצים והתיקייה fonts מתוך התיקייה שחולצה.
6. אשר החלפה ולחץ Commit changes.
7. המתן כשתי דקות ופתח מחדש את האתר.

אם עדיין מופיע העיצוב הישן
--------------------------
במחשב: לחץ Ctrl+F5.
בטלפון: סגור את האפליקציה לגמרי ופתח שוב.
אם עדיין ישן, פתח פעם אחת בדפדפן ורענן.

סנכרון
------
התחבר באותו אימייל במחשב ובטלפון.
אחרי שינוי, המתן כמה שניות או לחץ על סמל הסנכרון.
