HON Stitch v28 - הוראות עדכון קצרות

1. הורד את HON-Stitch-v28.zip וחלץ אותו.
2. בגיטהאב, בתוך המאגר של האפליקציה, לחץ Add file ואז Upload files.
3. העלה את כל הקבצים ואת התיקייה fonts מתוך התיקייה שחילצת.
4. אשר Commit changes והמתן כשתי דקות לפרסום GitHub Pages.
5. פתח את האתר קודם במחשב, המתן שיופיע "הכול מסונכרן", ואז פתח אותו בטלפון ורענן פעם אחת.

המידע הקיים נשמר: העדכון אינו מוחק תנועות, חשבונות, תקציבים, מטרות, ארנקים או יתרות פתיחה.
אין צורך להפעיל שוב את קובץ ה-SQL ואין צורך לשנות את Supabase.

מהעדכון הזה והלאה, המחשב והטלפון ממזגים שינויים במקום לדרוס את כל האפליקציה. בהגדרות נוסף גם אזור "סנכרון מוגן" עם גישה לגרסאות קודמות.
