איך לעדכן ל-HON v17
===================

1. חלץ את קובץ HON-v17-financial-maturity.zip.
2. היכנס למאגר hon-app שלך ב-GitHub.
3. לחץ Add file ואז Upload files.
4. העלה את כל הקבצים שחולצו, כולל:
   index.html, styles.css, app.js, cloud.js, sw.js,
   manifest.webmanifest, icon.svg ו-supabase-setup.sql.
5. אשר החלפה של הקבצים הקיימים ולחץ Commit changes.
6. המתן כדקה ופתח מחדש את האתר.
7. בטלפון: סגור ופתח את האפליקציה. אם הגרסה הישנה עדיין מופיעה,
   רענן פעם אחת את האתר או סגור את האפליקציה לגמרי ופתח מחדש.

חשוב
----
- אין למחוק את טבלת hon_data ב-Supabase.
- אין צורך לייבא מחדש את הגיבוי.
- הנתונים הקיימים שלך נשמרים בענן ובדפדפן ואינם נמצאים בקובצי הקוד.
- מומלץ לשמור את הגיבוי המלא שכבר הורדת עד שתוודא שהכול מוצג כרגיל.
