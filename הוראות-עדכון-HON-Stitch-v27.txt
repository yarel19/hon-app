HON Stitch v27 - הוראות עדכון קצרות

1. הורד את HON-Stitch-v27.zip וחלץ אותו.
2. בגיטהאב, בתוך המאגר של האפליקציה, לחץ Add file ואז Upload files.
3. העלה את כל הקבצים והתיקייה fonts מתוך התיקייה שחילצת.
4. אשר Commit changes והמתן כשתי דקות לפרסום GitHub Pages.
5. פתח מחדש את האתר במחשב ובטלפון ורענן פעם אחת.

המידע הקיים נשמר: העדכון אינו מוחק תנועות, חשבונות, תקציבים, מטרות או ארנקים.
אין צורך להפעיל שוב את קובץ ה-SQL ואין צורך לשנות את Supabase.

טיפ: בפעם הראשונה שתפתח את הסקירה, האפליקציה תשמור אוטומטית את יתרות הפתיחה של החודש. אם הן אינן מדויקות, לחץ "תיקון יתרות פתיחה" ועדכן אותן פעם אחת.
