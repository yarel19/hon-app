HON Stitch v49 — הוראות עדכון

מה עושים:
1. חלץ את HON-Stitch-v49.zip.
2. היכנס למאגר hon-app ב-GitHub.
3. לחץ Add file ואז Upload files.
4. העלה את כל התוכן שחולץ, כולל התיקיות fonts ו-supabase.
5. לחץ Commit changes והמתן 2–3 דקות לפרסום.

כדי להחיל גם את הסינון החדש בצד השרת, פרוס מחדש רק את הפונקציה הקיימת:

  npx supabase functions deploy hon-reminders --no-verify-jwt

חשוב:
- אין ליצור מפתחות VAPID חדשים ואין לשנות את VAPID_PUBLIC_KEY, VAPID_PRIVATE_KEY או VAPID_SUBJECT.
- אין לשנות את CRON_SECRET או את כותרת X-Cron-Secret במסגרת העדכון הזה.
- האפשרות Verify JWT with legacy secret צריכה להישאר כבויה.
- אין צורך להריץ מחדש את קובצי ה-SQL אם הטבלאות וה-Cron כבר קיימים.
- אין צורך לייבא גיבוי מחדש; הנתונים הקיימים נשמרים.

לאחר הפרסום:
- במחשב: בצע Ctrl+F5 פעם אחת כדי לקבל את v49. אזור ההתראות לא יוצג כלל.
- בטלפון: סגור ופתח מחדש את HON. אזור ההתראות יישאר בהגדרות.
- ההתראות עצמן נשלחות על ידי Supabase Cron גם כשהמחשב סגור, ולכן אינן תלויות ברענון של המחשב.
